## 🔮 Sobre o grupo

O CECC é um grupo de pesquisa e estudos para toda a **Politécnica**.
Ficamos um tempo em silêncio, mas a coruja renasceu das cinzas e voltou com tudo. 🔥🦉

Toda semana o grupo divulga um **Tema da Semana**, com cursos e materiais selecionados.
Este repositório guarda tudo isso em um só lugar, como uma **biblioteca**: se você perdeu uma semana, é só vir aqui e pegar o que ficou para trás.

---

## 📚 Como usar a biblioteca

1. Veja a **tabela de semanas** logo abaixo.
2. Clique na pasta do tema que te interessa.
3. Dentro dela você encontra o resumo da semana, os links dos cursos e os materiais de apoio.
4. Estude no seu ritmo. Não tem prazo. 🌙
