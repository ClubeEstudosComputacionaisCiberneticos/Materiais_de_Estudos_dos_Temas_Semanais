## 🔮 O que são Git e GitHub?

**Git** é a ferramenta que registra o histórico do seu código, e o **GitHub** é o lugar onde você guarda e compartilha esses projetos. Juntos, são a base de quase todo trabalho em tecnologia.

Esta semana reúne cursos para quem está começando e também para quem prefere aprender pela linha de comando ou pela interface visual.

> 💡 **Dica da coruja:** não precisa decorar os comandos. Pratique com projetos pequenos e o resto vem com o tempo. 🦉
